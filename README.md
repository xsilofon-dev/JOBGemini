# Tailscale Setup for Google Cloud Shell

Цей репозиторій містить сценарій для автоматизації встановлення та запуску Tailscale в ефемерному середовищі Google Cloud Shell.

## Як користуватися

1. Зробіть скрипт виконуваним:
   ```bash
   chmod +x setup-tailscale.sh
   ```

2. Запустіть його:
   ```bash
   ./setup-tailscale.sh
   ```

3. Перейдіть за посиланням, яке з'явиться в консолі, щоб авторизуватися у вашій мережі Tailscale.

## Особливості
- Оскільки Cloud Shell не підтримує `systemd` та мережеві пристрої TUN, скрипт запускає Tailscale в режимі `--tun=userspace-networking`.
- Всі системні зміни в Cloud Shell втрачаються після завершення сесії, тому цей скрипт потрібно запускати кожного разу при новому вході.

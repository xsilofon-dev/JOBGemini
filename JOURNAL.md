# JOBGemini: Журнал розробки та пам'ять проекту

Цей файл служить довготривалою пам'яттю для Gemini CLI. Тут фіксуються всі ключові дії, стан проекту та прийняті рішення.

## 📝 Історія дій

### [2026-04-25] - Початкове налаштування та Tailscale
- **Завдання:** Встановити та налаштувати Tailscale у Google Cloud Shell.
- **Проблема:** Cloud Shell не має підтримки `systemd` та TUN-пристроїв.
- **Рішення:** 
  - Tailscale встановлено через офіційний скрипт.
  - Демон `tailscaled` запущено вручну в режимі `--tun=userspace-networking`.
  - Налаштовано SOCKS5-проксі на порту 1055.
  - Виконано авторизацію через `force-reauth`.
- **Результат:** Пристрій успішно підключений до tailnet. Створено репозиторій `JOBGemini` зі скриптом автоматизації `setup-tailscale.sh`.
